🎯 Online Quiz Maker Web App
A full-stack web application that allows users to create, take, and manage quizzes with multiple questions and instant results.

🚀 Features
👤 User Registration & Login
📝 Create Quiz with Multiple Questions
✅ Select Correct Answers using Radio Buttons
📋 View Available Quizzes
🎯 Take Quiz with Multiple Choice Questions
📊 Instant Score Display
📱 Mobile Responsive UI
🛠️ Tech Stack
Frontend: HTML, CSS, JavaScript
Backend: Python (Flask)
Database: SQLite
IDE: VS Code
